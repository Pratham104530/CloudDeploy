# CloudDeploy

CloudDeploy is an automated CI/CD deployment platform
built to demonstrate modern DevOps practices.

## Project Goals

- Automate application testing and deployment.
- Containerize applications using Docker.
- Build CI/CD pipelines using GitHub Actions.
- Learn Jenkins for CI/CD automation.
- Deploy applications on AWS.
- Provision infrastructure using Terraform.
- Monitor application health using AWS CloudWatch.

## Technology Stack

- Linux
- Git and GitHub
- Python and Flask
- Docker and Docker Compose
- GitHub Actions
- Jenkins
- AWS
- Terraform
- AWS CloudWatch
